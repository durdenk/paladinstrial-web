# Paladin's Trial — Website

Static website for the **Paladin's Trial** Android game (`com.cukkacreatives.paladins_trial`) by Cukka Creatives.

## Pages

- `index.html` — game landing page
- `privacy-policy.html` — Privacy Policy
- `terms-of-service.html` — Terms of Service (`terms-of-use.html` is an identical copy)
- `app-ads.txt` — authorized ad sellers (Google AdMob)

## Publishing

Push these files to the root of a public GitHub repository and enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root). For `app-ads.txt` to be verified, it must be served from the root of the developer website domain listed in Google Play Console.
